# История изменений

Все заметные изменения проекта фиксируются в этом файле.

## Не выпущено

- Исправлен self-update для путей с кириллицей и другими не-ASCII символами: `.bat` заменен на PowerShell updater script.
- Статусные сообщения по задаче теперь отправляются ответом на исходное сообщение со ссылкой.
- Добавлена вкладка `Command` для настройки алиасов bot-команд с проверкой дублей.

## 0.1.3 - 2026-08-20

- Добавлено несколько download workers для параллельной обработки задач разных пользователей.
- Добавлен processing lock, чтобы задачи одного пользователя обрабатывались последовательно.
- Добавлены worker id в GUI-логи обработки очереди.
- Добавлен updater через GitHub Releases для собранного exe.
- Self-update перенесен в фоновый поток GUI.
- Добавлена проверка SHA-256 для скачанных release exe-файлов.
- Добавлен GitHub Actions workflow для release-сборок.
- Добавлен rate limiting для Telegram progress/status сообщений.
- Текущая версия отображается во вкладке Bot.
- Updater показывает текущую и последнюю доступную версию.
- Добавлены минимальные regression-тесты для core-логики.
- Обновлен учет технического долга.

## 0.1.0 - 2026-08-20

- Добавлен desktop GUI на PyQt6.
- Добавлена интеграция с Telegram bot.
- Добавлено скачивание TikTok-видео через `curl_cffi` с fallback на `yt-dlp`.
- Добавлены пользовательские настройки доставки и режим групповых пачек.
- Добавлена настройка автозапуска Windows.
- Добавлен PyInstaller spec для сборки exe.
