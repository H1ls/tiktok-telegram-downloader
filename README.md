# TikTok Telegram Downloader

Десктопное приложение для запуска Telegram-бота, который скачивает видео из TikTok, отправляет их пользователю и умеет копить ролики для отправки пачками в привязанную группу.

## Возможности

- GUI на PyQt6 с поддержкой системного трея.
- Telegram-бот на aiogram.
- Скачивание TikTok двумя способами:
  - прямой загрузчик через `curl_cffi`;
  - fallback через `yt-dlp`, если прямое скачивание не сработало.
- Прогресс скачивания в GUI-логах: проценты, MB, скорость, время или ETA.
- Режимы доставки для каждого пользователя:
  - `dm` - отправлять каждое видео сразу в личные сообщения;
  - `group_batch` - копить видео и отправлять пачкой в привязанную группу.
- Режим `ссылка + me` или `ссылка + мне`, чтобы отправить видео в тот чат, где была написана ссылка.
- Вкладка настроек:
  - Telegram bot token;
  - папка хранения настроек;
  - папка временного хранения/скачанных видео;
  - включение/выключение автозапуска с Windows.
- Кнопка обновления из Git.

## Требования

- Основная целевая платформа - Windows.
- Python 3.11+.
- Git, если нужна кнопка обновления через Git.
- `ffprobe` в `PATH` для проверки наличия аудиодорожки.
- Telegram bot token, созданный через BotFather.

Python-зависимости перечислены в [requirements.txt](requirements.txt).

## Установка

```powershell
git clone <repo-url>
cd tiktok_downloader
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

Если `ffprobe` не найден, установите FFmpeg и добавьте папку `bin` в `PATH`.

## Запуск

```powershell
python app.py
```

При первом запуске:

1. Откройте вкладку `Settings`.
2. Введите Telegram bot token.
3. При необходимости выберите папку хранения настроек.
4. При необходимости выберите папку временного хранения/скачанных видео.
5. Включите или выключите автозапуск с Windows.
6. Нажмите `Save settings`.
7. Перейдите во вкладку `Bot` и нажмите `Start`.

## Настройки

Настройки приложения хранятся в `config.json`.

По умолчанию приложение использует `config.json` рядом с проектом/приложением, если он уже существует. Если локального конфига нет, используется:

```text
%LOCALAPPDATA%\TikTokDownloader
```

При смене `Settings folder` рядом с приложением создается `storage.json`. В нем хранится путь к выбранной папке настроек.

Скачанные и ожидающие отправки видео хранятся в выбранной папке загрузок. Если папка не выбрана, используется:

```text
D:\TikTok
```

## Команды бота

| Команда | Описание |
| --- | --- |
| `/start` | Показывает краткую справку по боту и основным командам. |
| `/my` | Показывает текущие настройки пользователя: режим доставки, привязанный чат, размер пачки, очередь и качество. |
| `/route dm` | Включает режим отправки каждого скачанного видео сразу в личные сообщения пользователя. |
| `/route group` | Включает режим накопления видео и отправки пачкой в привязанную группу. |
| `/bind` | Привязывает текущую группу как целевой чат для пачек. Используется внутри нужной группы. |
| `/bind_id -1003115579453` | Привязывает группу по ID. Удобно использовать из личных сообщений с ботом. |
| `/batch 1..10` | Задает количество файлов, после которого бот отправит накопленную пачку в группу. |
| `/keep 1..1000` | Задает лимит хранения очереди/накопленных файлов для пользователя. |
| `/quality 360\|480\|720\|1080` | Задает максимальную высоту видео для скачивания через `yt-dlp` fallback. |
| `/status` | Показывает, сколько файлов сейчас накоплено и какой порог пачки установлен. |
| `/flush` | Принудительно отправляет накопленные файлы. В режиме `group_batch` отправляет в привязанную группу. |
| `/last` | В привязанной группе отправляет накопленные файлы в текущий чат. |
| `/id` | Показывает Telegram `user_id` пользователя. |

## Режимы доставки

`/route dm`

Видео скачивается и сразу отправляется пользователю в личные сообщения.

`/route group`

Видео сохраняются в папку пользователя и отправляются в привязанную группу, когда набирается нужное количество файлов.

## Привязка группы

В нужной Telegram-группе:

```text
/bind
```

Или из личных сообщений:

```text
/bind_id -1003115579453
```

## Отправка в текущий чат

После TikTok-ссылки можно написать `me` или `мне`:

```text
https://vt.tiktok.com/xxxxx/ me
https://vt.tiktok.com/xxxxx/ мне
```

В этом случае видео будет отправлено в тот чат, где была написана ссылка.

## Обновление через Git

Кнопка `Update from Git` выполняет:

```text
git fetch --prune
git pull --ff-only
```

Этот сценарий рассчитан на запуск из исходников. Для собранного `.exe` лучше делать отдельный release/update-механизм.

## Структура проекта

```text
app.py                    точка входа PyQt-приложения и service thread
bot/                      Telegram-команды и обработчик ссылок
core/                     основная логика приложения
core/downloaders/         стратегии скачивания TikTok и fallback
gui/                      PyQt-виджеты и tray
requirements.txt          Python-зависимости
```

Ключевые модули:

- `core/service.py` - lifecycle бота, polling и worker orchestration.
- `core/job_processor.py` - обработка одной задачи скачивания.
- `core/job_queue.py` - очередь, состояние и расчет позиции.
- `core/flush_service.py` - ручная и стартовая отправка накопленных пачек.
- `core/settings_service.py` - загрузка и сохранение GUI-настроек.
- `core/updater.py` - обновление через Git.
- `core/autostart.py` - автозапуск Windows через registry.
