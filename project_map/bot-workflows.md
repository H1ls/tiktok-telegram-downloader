# Сценарии Telegram-бота

## Прием TikTok-ссылки

1. `bot.link_handler` принимает текстовое сообщение, пропускает команды и ищет TikTok URL.
2. Ссылка раскрывается в отдельном thread через `asyncio.to_thread(expand_url, ...)`.
3. Фото-карусель отклоняется с сообщением о неподдерживаемом формате.
4. Создается `Job` с user ID, chat ID, исходной ссылкой и message ID.
5. Суффикс `me` или `мне` задает текущий чат как `target_chat_id`; иначе целевой маршрут определится пользовательскими настройками.
6. Job помещается в `asyncio.Queue`, пользователю возвращается номер позиции.

## Скачивание и доставка

Worker берет Job, обновляет счетчики и получает processing lock пользователя. `JobProcessor` ограничивает параллельные скачивания semaphore, вызывает downloader через `asyncio.to_thread`, проверяет наличие аудиодорожки и выбирает маршрут:

| Условие | Результат |
| --- | --- |
| Указан `target_chat_id` в Job | Отправка в чат, где пользователь написал ссылку с `me`/`мне`. |
| `delivery_mode == dm` | Попытка отправки пользователю в личные сообщения; при ошибке выполняется попытка отправить исходному чату. |
| Иной режим доставки | Файл остается в папке пользователя; при достижении порога и наличии привязанной группы запускается flush. |

Для групповой отправки используются пользовательский `batch_size` и `target_chat_id`. После запуска сервиса startup flush проверяет сохраненные настройки и уже накопленные медиафайлы.

## Команды

Команды могут иметь настраиваемые алиасы. Основные обработчики в `bot/commands.py`:

| Команда | Эффект |
| --- | --- |
| `/start`, `/my` | Справка и просмотр настроек/состояния пользователя. |
| `/route dm`, `/route group` | Переключение личной доставки или накопления пачек. |
| `/bind`, `/bind_id <chat_id>` | Привязка целевой группы. |
| `/batch 1..10`, `/keep 1..1000`, `/quality 360\|480\|720\|1080` | Сохранение пользовательских параметров. |
| `/status` | Число накопленных файлов и порог пачки. |
| `/flush` | Принудительная отправка накопленных файлов согласно режиму. |
| `/last` | Отправка накопленного в привязанную группу из самой группы. |
| `/id` | Показ Telegram user ID. |

## Границы сценария

- Поддержка `InputMediaPhoto` в sender не означает, что TikTok photo carousel скачивается: link handler явно отклоняет такие ссылки.
- Порог пачки — настройка конкретного пользователя; отправка ограничивается параметрами альбомов и размерами из `AppConfig`.
- Сетевой сбой при отправке медиа может оставить неизвестным факт доставки. Не обещать exactly-once или отсутствие дублей.
- Очередь незавершенных ссылок не переживает перезапуск процесса; уже скачанные файлы хранятся на диске.
