## Примечание по workers

Сервис запускает несколько worker'ов для общей очереди задач. Задачи разных пользователей могут обрабатываться параллельно, а задачи одного пользователя проходят через отдельный processing lock и сохраняют последовательность обработки.

Лимиты:

- количество worker'ов задается константой `AppConfig.DOWNLOAD_WORKERS`;
- реальный параллелизм скачивания дополнительно ограничен `_download_pool`;
- flush/пачки по пользователю по-прежнему защищены отдельным `user_lock`.
